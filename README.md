# SAUCE

A mobile-friendly personal Hungarian recipe collection with handwritten family recipes, recipe importing and offline support.

[Open SAUCE](https://theparsifal21.github.io/Sauce/)

## Usage
Browse your recipes on mobile or desktop. Use recipe import where supported and verify imported ingredients and quantities.

## Deployment
Enable GitHub Pages from the main branch, root directory. Install from a supported browser when available.
